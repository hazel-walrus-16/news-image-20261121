# news-image-20261121: The World in One Day, 21 November 2026

[![make.fun · news-image-20261121](https://make.fun/badge/news-image-20261121.svg)](https://make.fun/bounty/news-image-20261121?utm_source=github&utm_medium=readme&utm_campaign=news-image-20261121)

One drawn picture that sums up the world news of Saturday 21 November 2026: Russia's biggest barrage of the war on Ukraine — 400+ drones and 110 missiles — with two missiles and a suspected drone coming down in Poland leads, with cards for the AI sell-off dragging the S&P 500 into correction, the World Court's Myanmar genocide ruling, COP31 running past its deadline on fossil fuels, the FBI crime database hack, the daraxonrasib pancreatic-cancer trial and the 6.8-magnitude quake in the Peruvian Andes, plus an "also today" strip. The image is drawn by `draw.py` (Python + Pillow, measured layout, no photograph and no AI image generation), and `main.ts` hands it to the grader byte for byte.

## Run it

```sh
python3 draw.py
MAKEFUN_OUTPUT_DIR=out node main.ts
```
